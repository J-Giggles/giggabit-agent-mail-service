# Governance

J-Giggles is the initial maintainer and final decision-maker for the v0.x
preview. Design discussion and implementation happen through GitHub Issues and
pull requests. Maintainers may add collaborators as the contributor community
develops.

Security invariants take priority over compatibility and convenience. Changes
to identity, credential handling, message trust, outbound controls,
attachments, or network exposure require tests and maintainer review.

No contributor licence agreement or Developer Certificate of Origin is
required. Contributions intentionally submitted for inclusion are handled by
section 5 of the Apache License 2.0 unless explicitly marked otherwise.
