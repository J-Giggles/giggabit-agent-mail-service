# Support

This project is community-supported on a best-effort basis. It has no response
time, uptime, compatibility, or production support service-level agreement.

Use GitHub Issues for reproducible bugs and GitHub Discussions for usage
questions once Discussions is enabled. Do not post credentials, mailbox
addresses, message content, logs, databases, provider identifiers, hostnames,
or diagnostic output that has not been reviewed and redacted.

Security vulnerabilities follow [SECURITY.md](SECURITY.md), not the public
issue tracker.
